# Margin Trading (融资融券)

* 融资: **LONG SECURITY**, Borrow money from the broker, and use it to buy security; if the security price rises, borrower returns the money to the broker, earning a profit.
* 融券: **SHORT SECURITY**, Borrow security from the broker; if the security price falls, borrower returns the security to the broker, earning a profit.

* 融资: LONG SECURITY
    * 融资买入额: (Margin Purchases) New money borrowed TODAY to buy the security.
    * 融资偿还额: (Margin Repayments) Principal + interest repaid TODAY by investors.
    * 融资余额 (Outstanding Margin Balance) Total unpaid margin loan principal at market close . This is the cumulative stock variable.
    * 融资卖出额: (Margin Sales) New security sold TODAY to sell the security.

* 融券: SHORT SECURITY
    * 融券卖出量 (Short Sales Volume) previously borrowed security are sold short TODAY.
    * 融券偿还量 (Short Coverings) previously borrowed security returned to the lender TODAY.
    * 融券余量: (Outstanding Short Interest) The amount of security that the broker holds in the account of the borrower.
